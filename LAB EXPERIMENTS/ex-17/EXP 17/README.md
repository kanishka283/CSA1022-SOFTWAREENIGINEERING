# Experiment 17: Flask API Containerized with Docker, Pushed to Docker Hub and Deployed on Kubernetes

**Tools Used:** Docker & Kubernetes  
**Course Outcome:** CO3

## Aim
To flask API Containerized with Docker, Pushed to Docker Hub and Deployed on Kubernetes.

## Procedure
1. Write the Flask API and Dockerfile
2. Build and test locally
3. Push to Docker Hub
4. kubectl apply -f k8s/
5. Verify with kubectl get pods,svc

## Deliverables Checklist
- [ ] app.py, requirements.txt, Dockerfile
- [ ] k8s/deployment.yaml, k8s/service.yaml
