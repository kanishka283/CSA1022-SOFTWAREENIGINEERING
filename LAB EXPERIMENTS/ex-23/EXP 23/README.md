# Experiment 23: Multi-Container Application (Frontend, Backend, Database) on Kubernetes with Scaling

**Tools Used:** Docker, Kubernetes  
**Course Outcome:** CO3

## Aim
To multi-Container Application (Frontend, Backend, Database) on Kubernetes with Scaling.

## Procedure
1. Create frontend, backend and database manifests
2. kubectl apply -f k8s/
3. Scale the backend with kubectl scale
4. Verify pods and services
