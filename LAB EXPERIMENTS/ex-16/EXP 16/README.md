# Experiment 16: Static Website Containerized and Served with Docker and Nginx

**Tools Used:** Docker  
**Course Outcome:** CO3

## Aim
To static Website Containerized and Served with Docker and Nginx.

## Procedure
1. Create index.html
2. Write the Dockerfile using nginx:alpine
3. docker build -t static-site .
4. docker run -d -p 8080:80 static-site
5. Open http://localhost:8080
