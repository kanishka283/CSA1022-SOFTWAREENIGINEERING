# Experiment 19: Continuous Deployment of a Dockerized Application using GitHub Actions

**Tools Used:** Docker  
**Course Outcome:** CO5

## Aim
To continuous Deployment of a Dockerized Application using GitHub Actions.

## Procedure
1. Add Docker Hub credentials as GitHub Secrets
2. Add the workflow in .github/workflows/deploy.yml
3. Push to main to trigger the workflow
4. Verify the image on Docker Hub
